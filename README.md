# eCommerce templates

Static website templates for the eCommerce category.

- `manifest.json` lists every template with its metadata.
- Each template folder holds `AGENTS.md`, `package.json`, `preview.png`, and `src/` (site files).
- Run a template locally: `cd <template> && npx serve src`.

Preview gallery: https://digital-brand-site-templates.github.io/ecommerce/
